### Assessing data quality

Our dataset is divided in cyclists and races; in the cyclists dataset we have informations about cyclists like name, birth year, weight, height and nationality while in the races dataset we have one instance for each cyclist that took part at the race plus information about the race, for this reason we have more than one instances for the same race.

The cyclists dataset has 6124 instances instead the races dataset has 589865 in which only 5281 are unique races.
